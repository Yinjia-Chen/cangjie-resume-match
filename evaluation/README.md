# 评估方法与指标占位说明

当前仅定义评估计划，尚无标注数据、运行脚本或实验结果。

## 流程

1. 建立约 5 个岗位、200 份脱敏简历、300 个简历—岗位配对的数据集。
2. 双人独立盲评“是否推荐面试”和 0～3 级相关性；保留原始标注并裁决分歧。
3. 按候选人划分开发集、测试集；仅用开发集调整提示词、权重和阈值。
4. 冻结模型和配置，运行关键词规则基线及系统，按岗位和格式对比。
5. 保存错误案例、耗时、API 成本及评估报告；单独报告待核实样本与覆盖率。

## 指标

以人工推荐为正类：TP 为正确推荐、FP 为错误推荐、FN 为漏筛、TN 为正确不推荐。

- Accuracy = (TP + TN) / 全部样本数。
- Precision = TP / (TP + FP)。
- Recall = TP / (TP + FN)。
- F1 = 2 × Precision × Recall / (Precision + Recall)。
- NDCG@10：以人工相关性等级计算每个岗位前十名排序质量，再按岗位汇总。
- 关键字段抽取 F1：与人工字段标注比较，预先固定同义词和日期等归一化规则。
- Cohen’s κ：比较裁决前两位标注者的推荐标签。
- 理由与题目质量：人工评价证据真实性、岗位相关性、问题可用性，评分量表在实验前固定。
- 效率：单份处理耗时与 API 成本。

分母为零时标记指标不可计算并说明原因。报告测试样本数、类别分布及配置版本，不预设或编造准确率。
