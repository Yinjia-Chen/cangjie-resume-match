## 维护约定

- 沿用学校模板的布局与格式，教师意见、评审评分和签字由相应人员填写。
- 技术栈与功能定义须与实际工程一致，区分已实现内容、后续计划及尚未开展的实验。
- 任务书和开题报告的进度安排保持一致；参考文献按学校要求维护。
- 更新已有报告时直接修改对应文件；需要保留历史稿时，在文件名中注明日期或版本。
- 临时转换文件、排版检查图片和中间产物不存入本目录。

技术方案与实现记录仍保存在上级 `docs/` 目录，答辩演示材料位于 `docs/presentation/`。
